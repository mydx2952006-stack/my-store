# El Mahdy Store Full Stack
## التشغيل
1. ثبت Node.js LTS.
2. افتح Terminal داخل المجلد.
3. نفذ: `npm install`
4. ثم: `npm start`
5. افتح `http://localhost:3000`
6. لوحة الطلبات: `http://localhost:3000/admin`

الطلبات محفوظة محليًا في `data/orders.json`. هذا إصدار تعليمي محلي، وليس جاهزًا للنشر العام قبل إضافة تسجيل دخول للوحة الإدارة وحماية البيانات وقاعدة بيانات مستضافة.
